
# UduStay - Lodge Booking System

# How to run this project locally:
1. Place the `udustay2` folder into your `C:\xampp\htdocs\` directory.
2. Start Apache and MySQL in XAMPP.
3. Open `http://localhost/phpmyadmin/`, create a database named `udustay_db`.
4. Click on `udustay_db`, go to the **Import** tab, and upload the `udustay_db.sql` file included in this folder.
5. Open your browser and go to: `http://localhost/udustay2/index.html`
